# S5, second control change — marking note

Written on 17 October 2026, before any answer of round 2 was marked, and frozen
from that point. It applies to Test 3 and Test 4.

## What it records

In round 2 the Turkish paragraph of S5 carries a second control change (see
`instrument.md`, "Design of the copying probe"):

| | Turkish | Adyghe reference translation |
|---|---|---|
| Original (S4) | birbirlerini SEVEREK bu güzel güne ULAŞTILAR ("loving each other, they reached this beautiful day") | Тӏури шӏу зэрэлъэгъухэзэ мы мэфэ дахэм къэсыгъэх. |
| Changed (S5) | birbirlerini SEVMESELERDİ bu güzel güne ULAŞAMAZLARDI ("had they not loved each other, they could not have reached this beautiful day") | Тӏури шӏу зэрэмылъэгъущтыгъэхэмэ мы мэфэ дахэм къэсышъущтыгъэхэп. |

The change does not alter the meaning; it alters only the mood and the
construction. The sentence's meaning verdict is therefore given as usual, and this
note does not affect it. The note records only the question the instrument sets for
this change: did the tool carry the negative-conditional construction into Adyghe?

## The note

In the Note column of the Sentences sheet, on the S5 row that corresponds to this
sentence, one of the following is written:

- **Olumsuz-koşullu yapıyı aktardı** (carried the negative-conditional construction)
- **Olumsuz-koşullu yapıyı aktarmadı** (did not carry it)

If no decision can be made (the sentence is missing, unreadable, etc.), the
situation is written briefly instead.

## Application

- The note is agreed by the two evaluators, in the same way for Test 3 and Test 4.
- If the tool merged or split sentences, the note goes on the row where the content is.
- Round 1 did not contain this change; round 1's numbers are not affected.
